# LPC 素材署名

本目录的 PNG 与元数据来自 [Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator)，锁定在 commit `6a437fcecefbc7b82b401ca319046f80d67cdd2b`。

上游生成器的**代码**是 GPL-3.0，本项目未使用其任何代码——合成器为自研，只消费 `sheet_definitions/` 的 JSON 元数据与 `spritesheets/` 的 PNG。

上游多数资产是多重许可（任选其一遵守）。**本目录只保留提供 `CC0` 或 `OGA-BY` 选项的资产**，纯 `CC-BY-SA` / `GPL` 的资产在 vendoring 阶段即被丢弃，因此本项目不承担任何 ShareAlike 传染义务，只承担署名义务。下表的「采用许可」列即我们实际遵守的那一项。
